# AI 影片製作手冊（導演 → 生成 → 後製 → 輸出）

這份手冊整理自兩支已完成的影片：專題展示片（3 分鐘、24 鏡、三個角色）與 UVa 10327 解題講解片（2 分 26 秒、講師＋程式動畫＋流程圖）。
目的是讓**任何一個能執行指令、能操作瀏覽器的 AI 代理**（或照著做的人）不依賴特定模型，就能做出同等品質的影片。

所有判斷都寫成規則、範本、數字門檻與檢查清單；遇到手冊沒寫到的情況，照「品質標準」那一節自行判斷，並記錄在專案的製作紀錄裡。

## 快速開始（clone 之後）

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1     # Windows；macOS/Linux 用 bash setup.sh
.\.venv\Scripts\Activate.ps1
python 工具/make_anim.py 範例/UVa10327/project.json    # 約 3 分鐘：輸出 3 段解說動畫
python 工具/assemble.py  範例/UVa10327/project.json    # 組裝全片＋燒字幕
python 工具/qa.py        範例/UVa10327/project.json    # 自動驗收
```

成品在 `範例/UVa10327/成品/UVa10327講解_字幕.mp4`（約 2 分 25 秒）。純動畫版把路徑換成 `範例/純動畫_UVa10327/project.json`（旁白已附；要重新產生先跑 `python 工具/tts.py ... --force`）。`check_env.py` 可隨時重新檢查環境。
git 顯示中文檔名為亂碼時：`git config core.quotepath false`。

## 分工原則（最重要的一條）

**AI 影片模型只負責「人」：出鏡、表情、動作、說話。凡是要讓觀眾看清楚的東西——文字、數字、程式碼、陣列、圖表、App 畫面、字卡、字幕——一律用程式產生後製上去。**

理由：影片模型生成的文字幾乎都會糊掉或亂碼；數字與步驟需要精準對時；而且程式產生的畫面不扣點、可無限重做。

| 內容 | 做法 |
| --- | --- |
| 人物出鏡、說話 | Flow 影片（每鏡 ≤ 8 秒）；不用 Flow 時改成動畫字卡（見 05） |
| 旁白、配音、補錄台詞 | Flow「語音試聽」（不扣點）；或 `工具/tts.py`（edge-tts）、自己錄音 |
| 解說動畫（陣列、公式、程式碼逐行反白） | HTML 動畫 → `make_anim.py`，時間點跟著旁白長度走 |
| 流程圖 | Archify（選用）或同一套 HTML 動畫 |
| 手機／筆電上的 App 畫面 | 實際前端截圖或錄屏，追蹤貼到影片裡的螢幕，或做全螢幕插入 |
| 字卡（「隔天下午」、片尾） | HTML 動畫或圖片轉影片 |
| 字幕 | `assemble.py` 依說話時間自動排並燒錄 |

## 品質標準（交付前每條都要成立）

1. **畫面**：同一角色每鏡外型一致（髮型、衣服、配件）；場景固定元素一致；道具在對的手上、不飄浮、不變形；畫面中沒有糊掉的文字（螢幕只發光）。
2. **聲音**：台詞一字不差、沒有唸錯字（台灣讀音）、口音一致；每個角色永遠同一個聲音；沒有爆音；整片響度約 −16 LUFS、真峰值 ≤ −1 dBFS。
3. **字幕**：與說話同步（誤差 < 0.3 秒）、每行 ≤ 22 字、不蓋住畫面重點、不重疊、閱讀速度 ≤ 9 字/秒。
4. **節奏**：每句旁白前後有 0.5～1 秒呼吸；沒有超過 2 秒的意外靜音或黑畫面；動畫的重點在旁白講到它的那一刻出現或反白。
5. **內容**：講解類影片的每個結論都正確（程式要真的跑過、例子要算過）；腳本裡每一鏡都在成品裡。
6. **紀錄**：製作紀錄寫明每一鏡的來源檔、花了多少點、哪些地方尚未人工確認。

## 代理行為規則

- **花錢、花點數、對外發送之前一定先問使用者**：每支 Flow 影片都要使用者（或使用者事先授權的預算）核准；不要按「一律核准」。
- **不要謊報驗收結果**：自動檢查通過 ≠ 好看好聽。沒試聽過就寫「尚未試聽」。
- **一次只改壞掉的那一段**：所有腳本都能單段重做（`make_anim.py project.json a2`），組裝很快，不要整片重生。
- **舊版不要刪**：被取代的檔案移到 `舊版/` 並在紀錄裡寫原因。
- **每完成一個階段就更新製作紀錄**（專案資料夾裡的 `腳本.md` 或 `CLAUDE.md`／`AGENTS.md` 之類的專案說明檔），讓下一個接手的代理不用重新摸索。
- 帳號密碼不寫進任何檔案；需要登入時請使用者自己登入。

## 環境需求

- Python 3.10+；套件見 `requirements.txt`，`setup.ps1`／`setup.sh` 會建 `.venv`、安裝套件與 Chromium，再跑 `check_env.py`。
- ffmpeg 由 `imageio-ffmpeg` 提供，不用另外裝。
- 繁體中文字型：Windows 內建「微軟正黑體」`msjhbd.ttc`、思源黑體 `NotoSansTC-VF.ttf`；其他系統改 `project.json` 的 `subtitle.font_file` 與動畫 HTML 的 `@font-face`。
- 選用：Node.js＋Archify（流程圖動畫）。
- Google Flow 帳號（付費方案，影片扣點；圖片與語音試聽不扣點）。
- 路徑可以有中文，但 OpenCV 讀寫中文路徑要用 `np.fromfile`＋`cv2.imdecode`／`cv2.imencode(...).tofile`；Docker 掛載則先複製到純英文路徑。
